## Prueba de cascada
- Element selector (h2 { color: blue; }) → result: blue
- Class (.demo-title { color: green; }) → result: green
- ID (#demo-title { color: purple; }) → result: purple
- Inline style (style="color: orange") → result: orange

Explanation: Specificity rules determine which rule applies; inline style overrides ID/class/element.
